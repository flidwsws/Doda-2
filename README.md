# BONKAi

Чёрно-белая пиксельная RPG на выживание в стиле дарк-фэнтези. Собственные спрайты и отрисовка Canvas, без игровых зависимостей.

## Играть онлайн

**[Открыть BONKAi](https://dodabonk.aglowchalk.chatgpt.site)**

Игра доступна всем по ссылке. Публикация размещена на Sites.

## Локальная версия для ПК

**[Скачать BONKAi для Windows, macOS и Linux](https://github.com/flidwsws/Doda-2/raw/refs/heads/main/downloads/BONKAi-Offline.zip)**

Распакуйте ZIP и откройте `BONKAi/BONKAi.html` двойным щелчком. Нужен только современный браузер. Сервер, установка программ, аккаунт и интернет для игры не требуются: код, графика и шрифты встроены в один HTML-файл.

Рекорды хранятся в браузере при доступном локальном хранилище и не синхронизируются с онлайн-версией.

## Запуск

Откройте `dist/index.html` в браузере или запустите статический HTTP-сервер из `dist/`.

## Управление

- WASD / стрелки — движение.
- Пробел — рывок с короткой неуязвимостью, перезарядка 3 секунды.
- ESC — пауза.
- Атака автоматическая по ближайшим врагам.
- На телефоне доступны джойстик и кнопка рывка.

Собирайте опыт, выбирайте улучшения и выживите пять минут. Хранитель появляется каждую минуту до четвёртой включительно. Для победы нужно уничтожить всех появившихся хранителей.

Три доступных героя, девять улучшений, разные враги, магические снаряды, критические удары, лечение, локальные рекорды, синтезированные звуки. Данные сохраняются только в localStorage браузера. Пиксельные шрифты включены в исходники и загружаются локально.

## Карта мира

Площадь карты увеличена в девять раз: размеры — 9900 × 9900 игровых единиц. Доступны пять областей: Пепельный лес, Старое кладбище, Руины собора, Безмолвная пустошь и Мёртвая низина. В каждой есть свой ландшафт и центральный ориентир.

Мини-карта показывает героя, границы экрана и центры областей. Счётчик отмечает посещённые области за текущий забег. Декорации создаются небольшими участками вокруг камеры; память кэша ограничена.

## Герои

- **Грим** — воин, +20% урона.
- **Морвен** — друид, +40% здоровья.
- **Нокс** — разбойник, +25% скорости.

Рекорды прежних персонажей автоматически переносятся под новые имена.

## Оформление

Пепельный лес, сухие деревья, надгробия, готические руины и белое пламя. Герои и враги отрисованы собственными пиксельными спрайтами в низком разрешении без сглаживания. Палитра состоит из чёрного, белого и серых оттенков. Опыт отмечен ромбами, лечение — крестами.

## Пересобрать локальную версию

Из корня репозитория выполните `python3 scripts/build-offline.py`. Используется только стандартная библиотека Python 3, без скачивания зависимостей. Результат: `offline/BONKAi.html` и `downloads/BONKAi-Offline.zip`.

## Файлы

- `dist/index.html` — интерфейс.
- `dist/style.css` — адаптивные стили.
- `dist/game.js` — игра, пиксельные спрайты и отрисовка.
- `dist/theme.css` — монохромная пиксельная тема.
- `dist/assets/` — локальный шрифт Press Start 2P; лицензия SIL OFL в `OFL.txt`.
- `offline/BONKAi.html` — самодостаточная локальная версия.
- `downloads/BONKAi-Offline.zip` — архив для распространения.
- `scripts/build-offline.py` — сборщик локальной версии.
- `.openai/hosting.json` — конфигурация Sites.
