# DODABONK

Браузерная RPG на выживание, вдохновлённая жанром roguelite survivors. Собственная графика Canvas и механики без игровых зависимостей.

## Играть онлайн

**[Открыть Dodabonk](https://dodabonk.aglowchalk.chatgpt.site)**

Игра доступна всем по ссылке. Публикация размещена на Sites.

## Запуск

Откройте `dist/index.html` в браузере или запустите статический HTTP-сервер из `dist/`.

## Управление

- WASD / стрелки — движение.
- Пробел — рывок с короткой неуязвимостью, перезарядка 3 секунды.
- ESC — пауза.
- Атака автоматическая по ближайшим врагам.
- На телефоне доступны джойстик и кнопка рывка.

Собирайте опыт, выбирайте улучшения и выживите пять минут. Хранитель появляется каждую минуту до четвёртой включительно. Для победы нужно уничтожить всех появившихся хранителей.

Три доступных героя, девять улучшений, разные враги, магические снаряды, критические удары, лечение, локальные рекорды, синтезированные звуки. Данные сохраняются только в localStorage браузера. Внешние шрифты необязательны: предусмотрены системные замены.

## Файлы

- `dist/index.html` — интерфейс.
- `dist/style.css` — адаптивные стили.
- `dist/game.js` — игра и отрисовка.
- `.openai/hosting.json` — конфигурация Sites.
